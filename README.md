## 🚀 Come usare i notebook

### Opzione A — Google Colab (nessuna installazione)
Clicca il badge nella lezione che ti interessa oppure apri direttamente:  
`https://colab.research.google.com/github/<TUO-USERNAME>/informatica-lsa/blob/main/lezioni/01_numpy_grafici/lezione.ipynb`

### Opzione B — In locale
```bash
git clone https://github.com/<TUO-USERNAME>/informatica-lsa.git
cd informatica-lsa
pip install jupyter numpy matplotlib
jupyter notebook
```
